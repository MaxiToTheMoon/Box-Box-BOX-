# Box! Box! BOX!

The game combins an old school driving gameplay and vehicle maintenance strategy. Play as a racing team's mechanic: plan repairs, drive to the parts shop, and bring back the components needed to win the race.

## Repository

This repository contains the first Game Design Document and the game project.

- [Game Design Document](Documents/GameDesignDocument.md): gameplay, assets, technical decisions, team responsibilities, schedule, and changelog.
- [Prototype images](images/prototypes/): illustrations of the pits, driving section and parts shop.
- [Unity project on `dev`](https://github.com/MaxiToTheMoon/Box-Box-BOX-/tree/dev/Box!Box!BOX!): source project in `Box!Box!BOX!/`.

`main` contains the documentation; development takes place on `dev`. To open the game, check out `dev` add the project to Unity Hub using Unity **6000.0.85f1**. The project uses C#, with audio integration made through FMOD.
